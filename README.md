## 📖 Introduction

**L-Manager** is a lightweight PHP code management system.

Designed for developers who need a simple web interface to:
- Browse files
- Edit source code
- Manage folders
- Upload files
- Rename files
- Delete files

---

## ✨ Features

- ✅ File Manager
- ✅ Code Editor
- ✅ Syntax Highlighting
- ✅ Upload File
- ✅ Rename File
- ✅ Delete File
- ✅ Folder Navigation
- ✅ PHP Support
- ✅ DB View Edit
